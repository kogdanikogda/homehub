# HomeHub

UI/UX-кейс: система умного дома. Основное устройство — настенный планшет (1366×1024), дополнительно два телефона: Марина (домочадец) и Алексей (админ).
Дизайн — в Figma, здесь — рабочий прототип на коде.

## Запуск

```bash
npm install
npm run dev      # локально
npm run build    # сборка в dist/
```

## Стек

React, TypeScript, Vite, CSS-переменные, Zustand. Шрифт Inter подключён локально.

## Структура

- `src/styles` — токены (цвета, отступы, радиусы) из Figma
- `src/components` — компоненты интерфейса
- `src/screens` — экраны планшета и телефонов
- `src/store` — состояние дома (комнаты, устройства, режимы, сцены)
- `src/lib` — вспомогательный код
- `scripts/contrast.mjs` — проверка контраста WCAG для пар токенов (`node scripts/contrast.mjs`)
