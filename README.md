# HomeHub

UI/UX-кейс: система умного дома. Основное устройство — настенный планшет (1366×1024), дополнительно два телефона: Марина (домочадец) и Алексей (админ).
Дизайн — в Figma, здесь — рабочий прототип на коде.

## Запуск

```bash
npm install
npm run dev      # локально
npm run build    # сборка в dist/
npm test         # тесты логики дома
npm run storybook
```

## Стек

React, TypeScript, Vite, CSS-переменные и CSS Modules, Radix UI, Zustand, Storybook, Vitest. Шрифт Manrope подключён локально.

## Демо

- Прототип: https://kogdanikogda.github.io/homehub/ — на стартовой странице планшет и оба телефона работают одновременно с одним состоянием дома. Сцена, выбранная на телефоне, сразу меняется на планшете, окна и подтверждения показываются только на том устройстве, где нажали.
- Переключатель сверху — одно устройство на весь экран; `?device=tablet|marina|alexey` в адресе открывает его сразу.
- Storybook: https://kogdanikogda.github.io/homehub/storybook/

## Структура

- `src/styles` — токены (цвета, отступы, радиусы) из Figma
- `src/components` — компоненты интерфейса
- `src/screens` — экраны планшета и телефонов
- `src/store` — состояние дома (комнаты, устройства, режимы, сцены)
- `src/lib` — вспомогательный код
- `scripts/contrast.mjs` — проверка контраста WCAG для пар токенов (`node scripts/contrast.mjs`)



## Логика дома

Всё состояние — в `src/store`: `data.ts` (комнаты, устройства, сцены), `logic.ts` (чистые правила), `useHome.ts` (действия). Тесты: `npm test`.

Правила, которые уже работают на планшете:

- режимы Home / Away / Vacation; Away включается с подтверждением и предупреждением об открытых окнах;
- возврат в Home — только по PIN (в прототипе `1234`), всегда включается сцена General;
- сцены доступны только в Home; одновременно активна одна;
- Cinema → Night: предупреждение, что ТВ и звук выключатся;
- правка устройства при активной сцене: предупреждение один раз, потом плашка «Modified · N changes» и окно изменений с «Reset to scene»;
- прогресс активации сцены; устройство, не ответившее, помечается «No response»;
- критические тревоги (вторжение — выключается по PIN, дым — подтверждается одним касанием), которые будят приглушённый экран;
- приглушённый экран после 2 минут бездействия.

Внизу страницы — панель прототипа: открыть окно, вызвать тревогу, включить Vacation (как будто с телефона Алексея), сделать так, чтобы ТВ не отвечал, пройти первую настройку панели (приветствие → роль → QR → готово; кнопка «Owner approves/declines pairing» выбирает, как ответит телефон владельца).

На планшете работают три страницы: Dashboard, Rooms (список комнат, карточка комнаты, личные комнаты только для просмотра) и Scenes (состав сцены, активация, сброс изменений). Плитка «Today’s energy» в шапке открывает окно энергии за день, неделю и месяц.


## Телефоны

Марина (домочадец): Dashboard, Rooms, Scenes — режимы Home/Away, смена сцены, личные комнаты только на просмотр. Алексей (админ): плюс Security (сигнализация, камеры, замок), Devices (добавление устройств, офлайн), Settings (PIN, пределы температуры, режим Vacation), редактор сцен и энергия. Телефоны не просят PIN: вход в Home выполняется сразу со сценой General. Фото камер — `src/assets/cams`.
